# Тест-кейсы системы интеллектуального анализа аудио

> **Примечание.**
> Часть 1 (TC-001 – TC-004) составлена для проектируемой системы интеллектуального анализа аудио. На момент публикации портфолио система находится в стадии проектирования, поэтому кейсы демонстрируют подход к тестированию, а не результаты выполнения.
> Часть 2 (TC-101 – TC-103) выполнена на реальном публичном сервисе Convertio (https://convertio.co/ru/audio-converter/) для демонстрации практических навыков.

## Часть 1. Проектируемая система

### TC-001. Успешная загрузка mp3-файла

**Приоритет:** High
**Тип:** Позитивный
**Предусловие:** Открыта страница загрузки аудио

**Шаги:**
1. Нажать «Выбрать файл»
2. Выбрать файл `test_audio.mp3` (валидный, 3 МБ, 30 сек)
3. Дождаться завершения загрузки

**Ожидаемый результат:**
- Файл загружен
- Отображается имя `test_audio.mp3`
- Отображается размер `3 МБ`
- Отображается длительность `00:30`
- Кнопка «Анализировать» активна

**Фактический результат:** —
**Статус:** Запланирован

### TC-003. Загрузка файла на границе максимального размера

**Приоритет:** Medium
**Тип:** Граничный
**Предусловие:** Известен лимит размера — например, 50 МБ

**Шаги:**
1. Нажать «Выбрать файл»
2. Выбрать `test_50mb.wav` (ровно 50 МБ)
3. Дождаться загрузки
4. Повторить с файлом `test_51mb.wav` (51 МБ)

**Ожидаемый результат:**
- Файл ровно 50 МБ загружается успешно
- Файл 51 МБ не загружается
- Показывается сообщение о превышении размера

**Фактический результат:** —
**Статус:** Запланирован

### TC-004. Отмена загрузки

**Приоритет:** Medium
**Тип:** Негативный / UX
**Предусловие:** Открыта страница загрузки, выбран большой файл

**Шаги:**
1. Начать загрузку файла `large.wav` (40 МБ)
2. Во время загрузки нажать «Отменить»

**Ожидаемый результат:**
- Загрузка прерывается
- Файл не попадает в систему
- Форма возвращается в исходное состояние
- Можно начать загрузку заново

**Фактический результат:** —
**Статус:** Запланирован
