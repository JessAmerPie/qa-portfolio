# QA Portfolio

Портфолио QA-стажёра. Учебные артефакты по тестированию: чек-листы, тест-кейсы, баг-репорты, коллекция Postman, SQL-запросы.

## Обо мне

Студент 4 курса направления «Информационные системы и технологии».
Тема курсовой и диплома — проектирование программной технологии интеллектуального анализа аудио.
Готовлюсь к стажировке в QA: понимаю важность проверки алгоритмов, данных и API.

## Навыки

- Виды тестирования: функциональное, регрессионное, интеграционное, дымовое
- Составление чек-листов, тест-кейсов, баг-репортов
- Тестирование API: Postman (GET, POST, PUT, DELETE, проверки статусов и полей)
- SQL: SELECT, WHERE, JOIN, GROUP BY, ORDER BY
- Git: clone, add, commit, push, pull
