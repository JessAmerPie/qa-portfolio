# Чек-лист тестирования системы интеллектуального анализа аудио

## UI / Отображение
- [ ] Страница загрузки аудио открывается корректно
- [ ] Форма отображается корректно на десктопе
- [ ] Форма отображается корректно на мобильном (адаптивность)
- [ ] Есть зона drag-and-drop для файла
- [ ] Кнопка «Выбрать файл» работает
- [ ] Кнопка «Анализировать» видна и активна при выбранном файле
- [ ] Кнопка «Анализировать» неактивна без файла
- [ ] Отображается прогресс загрузки файла
- [ ] Отображается прогресс обработки / анализа

## Загрузка файла — позитивные проверки
- [ ] Загрузка mp3-файла — успешно
- [ ] Загрузка wav-файла — успешно
- [ ] Загрузка flac-файла — успешно
- [ ] Загрузка файла через drag-and-drop
- [ ] Загрузка файла через кнопку выбора
- [ ] После загрузки отображается имя файла
- [ ] После загрузки отображается размер файла
- [ ] После загрузки отображается длительность аудио

## Загрузка файла — негативные проверки
- [ ] Загрузка файла неподдерживаемого формата (txt, pdf) — ошибка
- [ ] Загрузка пустого файла — ошибка
- [ ] Загрузка битого аудиофайла — ошибка
- [ ] Загрузка файла с нулевой длительностью — ошибка
- [ ] Загрузка файла больше максимального размера — ошибка
- [ ] Отмена загрузки — файл не отправляется
- [ ] Повторная загрузка того же файла — не дублируется

## Граничные значения
- [ ] Файл минимального допустимого размера — проходит
- [ ] Файл на 1 КБ меньше лимита — проходит
- [ ] Файл ровно на границе лимита — проходит
- [ ] Файл на 1 КБ больше лимита — ошибка
- [ ] Аудио минимальной длительности (например, 1 сек) — проходит
- [ ] Аудио максимальной длительности — проходит
- [ ] Файл с нестандартным именем (кириллица, пробелы, спецсимволы) — загружается корректно
- [ ] Файл с очень длинным именем — не ломает интерфейс

## Анализ аудио
- [ ] Анализ запускается после загрузки
- [ ] Анализ завершается за разумное время
- [ ] Результат анализа отображается корректно
- [ ] Результат содержит ожидаемые метрики (например, BPM, тональность, спектр)
- [ ] Результат можно скопировать или скачать
- [ ] Повторный анализ того же файла даёт тот же результат
- [ ] Анализ двух разных файлов даёт разные результаты

## Ошибки и исключения
- [ ] При обрыве соединения показывается понятное сообщение
- [ ] При ошибке сервера (500) показывается понятное сообщение
- [ ] При таймауте обработки показывается сообщение и предложение повторить
- [ ] Ошибка не приводит к падению интерфейса
- [ ] После ошибки можно повторить загрузку без перезагрузки страницы

## Безопасность
- [ ] Файл загружается по HTTPS
- [ ] Файл не сохраняется на клиенте после закрытия вкладки
- [ ] Нельзя загрузить исполняемый файл под видом аудио (например, exe с расширением mp3)
- [ ] Размер загружаемого файла ограничен на сервере, а не только в UI
- [ ] Пользователь не может получить доступ к чужим загруженным файлам

## API (для проверки через Postman)
- [ ] POST /upload возвращает 200 и id файла
- [ ] POST /upload без файла возвращает 400
- [ ] GET /analysis/{id} возвращает результат анализа
- [ ] GET /analysis/{id} для несуществующего id возвращает 404
- [ ] DELETE /file/{id} удаляет файл
- [ ] Ответы в формате JSON
